## 3. Identity chain

For each rendered case the generator asserts, and would abort on failure:

```
foreground_pixels( npz["gt"] )  ==  REMEDFILM_INTERNAL_PER_SAMPLE.gt_fg
```

This single equality ties together, for one `sample_id`:

1. the original RGB image (resolved from the GT path by a documented per-dataset rule),
2. the ground-truth mask the model was scored against,
3. the saved GlobalMedFiLM mask,
4. the saved ReMedFiLM FULL mask,
5. the Dice / IoU / HD95 values printed on the panel,
6. the routing decision printed on the panel.

Additional structural assertions:

| Check | Result |
|---|---|
| All 808 cases resolve a source image, GT, and both masks | pass |
| `SKIP_GLOBAL` cases have byte-identical global and final masks | pass |
| All three arrays are 512 × 512 before overlay | pass |
| Image ↔ mask alignment (lesion contrast inside vs outside GT) | pass — dermoscopy darker inside, polyp/stone brighter inside |
| GT/prediction centroid offset | ≤ 11 px of 512 on sampled cases |
| Resampling | aspect-preserving `_fit512` + centre pad, identical to the phase19 preprocessing contract; masks use `NEAREST` |

**Technical review of the figure.** Checked against
`docs/METHODOLOGY_IMPLEMENTATION_MAP.md`: node names, module order and the three outcome
labels match the implementation. No defect was found that required redrawing. Two wording
cautions are recorded rather than repaired, because the raster is the user-selected
authoritative figure:

1. The legend calls the dashed path "training-only dependency"; in the implementation the
   gain labels of stage 4 are computed from saved predictions, which is consistent with the
   dashed convention but is not a gradient path.
2. `ΔP (corrected local mask)` is drawn as a mask; in code the refiner emits a corrected
   probability map that is thresholded at 0.5 before composition.

Neither affects the architecture being depicted.

## 5. Redistribution status

The prediction panels embed individual example images. No dataset is redistributed.

| Domain | Source licence | Status in this repository |
|---|---|---|
| ISIC 2018 (Task 1) | **CC0** | unrestricted |
| BUSI-WHU | **CC BY 4.0** | included with attribution; attribution recorded in README and here |
| KUB-StoneX | **CC BY 4.0** | included with attribution |
| Kvasir-SEG | research / educational use; **commercial use requires written permission** | included as research illustration only — see limitation below |

> **Limitation — Kvasir-SEG.** Six Kvasir examples appear in `prediction_kvasir.png` and one
> in the combined gallery. They are published under the dataset's research/educational terms
> and must not be reused commercially without written permission from the dataset authors.
> If a downstream user requires an unambiguously permissive redistribution, the Kvasir panel
> is the one to remove.

Additional safety checks:

- No patient-identifiable information appears in any panel; only image pixels and masks.
- The BUSI-WHU patient-information workbook is **not** present in the repository.
- No checkpoint, spreadsheet, API key or credential is embedded in any figure.
- No panel contains a prediction that was not already saved on disk.
