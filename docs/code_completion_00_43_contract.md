# Additive software completion contract

This work does not advance scientific phases, authorize data access, freeze a
scientific release, or amend historical subjects. Synthetic evidence is technical
only. Existing phase records remain authoritative for scientific execution.

The Stage E reusable artifact API accepts explicitly supplied local files and
expected SHA-256 identities. It never discovers datasets or loads credentials.
Packaging validates all bytes before publishing a write-once manifest; incomplete
directories have no manifest and cannot be consumed. Verification rejects path
escape, symlinks, missing files, altered bytes and configuration drift. A caller
must retain the manifest digest independently; a hash is integrity, not authority.

Configuration binds preprocessing, model family, protocol, source, thresholds,
202 numeric router features and the 16-D task embedding (218 total). Historical
single-channel design text and the later RGB production recipe must not be silently
interchanged. The package records its exact preprocessing contract and source hash.
No model conversion or tolerance relaxation is allowed. Parity compares every
returned tensor/array and discrete decision exactly on caller-supplied synthetic
or independently authorized control inputs, with nonfinite values rejected.

Monitoring consumes numeric summaries, not images or patient metadata. Bounds are
supplied prospectively; exceedance reports CHECK_REQUIRED, never recalibrates.
The local registry records immutable version entries and append-only rollback
events. Registry operations are bookkeeping, not deployment authorization.

Regression: FULL FamilyBundle.load must enforce family=FULL for G/R/B/S before
model construction, matching the existing Lite loader's explicit family check.
