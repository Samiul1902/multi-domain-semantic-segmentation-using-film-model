## Metric definitions and assumptions

`binary_metrics` uses exact TP/FP/TN/FN on matching 2-D binary arrays. Dice = 2TP/(2TP+FP+FN), IoU = TP/(TP+FP+FN); both empty = 1, one empty = 0. Other zero-denominator ratios and relative area error with empty reference are null; balanced accuracy is null if either sensitivity or specificity is undefined. Signed area error is predicted minus reference pixels. `multiclass_metrics` is generic, not a claim that these datasets are multiclass; macro includes declared classes including both-empty classes, weighted uses reference support, micro pools one-vs-rest counts. Background is evaluated independently. No undefined observation is silently zero-filled.

`surface_metrics` measures distances between **8-connected boundary pixel centres**, using zero outside the image. HD95 is the 95th percentile of concatenated directed distances; Hausdorff is their maximum; ASSD their pooled mean; surface Dice is the proportion of both surfaces within the specified tolerance, with directed precision/recall. Equal boundary-pixel weights are **not** physical contour-length/surfel weighting and can bias anisotropic geometries. Spacing `(row,column)` is millimetres only when explicitly supplied; otherwise units are pixels. Any empty surface makes all boundary metrics null. Tolerance uses the same units. These definitions are not interchangeable with other HD95/ASSD/surface-Dice variants.

`c1_compatibility` is separately named, uses `>=0.5` and epsilon `1e-7` and float32 counts, matching the frozen helper on synthetic fixtures. Loss epsilon is different. Frozen C1 primary analysis must use selected-epoch `best_records`, not silently replace them with recomputation. `c1_primary` implements the declared mathematical resampling scheme and checks a caller-declared roster and six run statuses, but **does not authenticate records or independently verify the VAL808 roster/run evidence, and does not authorize C1**. A future audited adapter must check those requirements before any claim. C1 is selection-consumed development evidence, not independent generalization.

## Input and aggregation

`validate_artifacts` accepts only in-memory binary arrays and explicit metadata; it reads no files. `freeze_artifacts` makes a detached immutable byte snapshot before evaluation. Its allowlist is `TRAIN`, `VAL`, `SYNTHETIC`, and rejects protected/unknown splits. SHA-256 binds canonical metadata and array dtype/shape/bytes; the evaluation-code digest must match the running package. Hashes are not signatures or proof of population identity. For declared VAL input, the C1 wrapper also requires frozen four-domain counts (357/84/87/280), but authentic roster membership remains externally audited. A malicious caller can lie about split identity; real use requires external authorization and provenance enforcement. One artifact set shares checkpoint/model/seed/dataset/split/schema/threshold. Patient/subgroup fields are optional and absent fields are explicitly unavailable. Only annotated subclass results can be meaningful; this foundation reports `NOT_AVAILABLE` for existing binary tasks. Group summaries retain missing counts; an unavailable patient group is **not a patient-level estimate**. Equal-domain macro requires all four complete domain means; it is not pooled Dice. Failure categories describe mask-level errors, not causal diagnoses.

## Statistics

`paired_bootstrap` resamples cases or patient clusters within each domain, preserves matched treatment/control and common draws across fixed seeds, and computes image-weighted domain means followed by equal-domain/equal-seed mean. Its percentile interval describes case/cluster sampling conditional on fixed runs; it does not represent seed or selection uncertainty. Missing or inconsistent paired rows abort; C1 requires KUB patient IDs. Non-KUB image sampling may understate uncertainty where latent patients recur. Seed SD is descriptive only. Holm, Bonferroni and BH utilities require a predeclared family and assumptions; no C1 secondary significance claim is authorized. Budget summaries are descriptive, and do not prove equal-budget fairness. Generic C2/C3 utilities are not an approved prospective protocol.
