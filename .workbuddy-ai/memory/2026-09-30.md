### Gotcha worth remembering: address-normalisation corrupts base64 image payloads
The reviewer-notebook determinism pattern normalises heap addresses (`0x[0-9a-fA-F]{6,}` -> `0xADDR`)
so object reprs do not poison the SHA. Applied blindly to **every** output string, it also rewrote
the **`image/png` base64 body** — a base64 string can legally contain the literal chars `0x` followed
by >=6 hex-ish chars — silently mutating a figure (observed: a 2-byte-short payload with no `IEND`
chunk, i.e. a "corrupt" embedded PNG). **Fix:** restrict normalisation to text-ish MIME types
(`text/plain`, `text/markdown`, `text/html`, `text/latex`, `application/json`, `text/csv`) + stream
text, and assert every embedded PNG still has correct magic + a trailing `IEND` **after** the write.
Also: a strict `data[-8:-4] == b"IEND"` check is wrong — it only holds for an EMPTY IEND (length 0);
a non-empty IEND is spec-valid. Use "`IEND` within the trailing 12 bytes, then PIL open+verify".

### Audit-script gotcha (worth reusing)
When a gate asserts "safety facts are zero/false", do NOT write them as bare booleans and then
`all(checks.values())` — the correct value `0`/`False` is falsy and trips the aggregate. Instead keep
each check as *the asserted fact* and compare separately against an `EXPECTED` map for the
zero-valued facts (`v == EXPECTED[k]`) while requiring `is True` for the ordinary boolean gates. Also:
when substring-matching a paragraph inside markdown, normalise BOTH whitespace and blockquote `>`
markers — in `TASKS.md` the paragraph is a `>` blockquote, so line wraps leave `>` tokens that break a

### Gotcha (reusable)
When auditing whether a "frozen contract" is complete, do not stop at the field that *names* the
procedure (e.g. "deterministic 5-fold group-safe CV") — that is a label. Check for the numeric
parameters and the assignment/monitor rules. A useful test: does a **sibling** block in the same
frozen artifact specify it fully (here the refiner's `crossfit` + `final_refiner` do, the router's do
not)? Sibling asymmetry is strong evidence of a genuine gap rather than an omission of wording.
